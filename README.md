# Simple User Authenticator

This is a lightweight authentication system built with **JavaScript**, **Express**, and **EJS** for rendering views. It uses **MongoDB** for data storage and provides basic **user registration** and **login** functionality with password hashing for security.

## Features

- User registration with email and password  
- User login with authentication validation  
- Passwords are securely hashed using **bcrypt**  
- MongoDB is used to store user credentials  
- EJS views for registration and login pages  

## Tech Stack

- Node.js  
- Express  
- EJS  
- MongoDB (via Mongoose)  
- bcrypt
